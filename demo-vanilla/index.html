Demo Tabulator — JavaScript vanilla

Trois sources de donnees, une seule bibliotheque : tri, recherche, filtres, edition et persistance.

Source : fichier data/employees.json charge directement par le navigateur (pas d'appel backend). Toutes les operations (tri, recherche, filtres) sont effectuees cote client. Les editions restent locales (aucune API de persistance pour une source JSON statique).

Source : GET/PATCH /api/employees-api (jeu de donnees en memoire cote serveur, 200 lignes). Lecture et ecriture passent par l'API ; tri/recherche/filtres restent cote client (petit volume).

Source : GET/PATCH /api/employees (table SQLite, 5000 lignes). Tri, filtres, recherche globale et pagination sont tous evalues cote serveur pour rester performant sur un gros volume.
